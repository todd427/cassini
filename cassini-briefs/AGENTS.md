# Shared agent instructions
Read PRD.md and CONTRACT.md first. Build only your assigned workstream. Preserve contract v0.1; propose changes to human integrator, do not implement breaking changes unilaterally. Use separate branches/worktrees; do not overwrite others' files. No credentials, invented data, hidden network calls or production safety claims. Distinguish genuine data, synthetic claims and fixtures. Record blockers and exact verification commands. Run tests, commit scoped work and report changed files, results and unresolved issues. Never deploy publicly or incur costs without human approval. Prefer reproducible local execution and simple dependencies.
