Audited against `cassini-briefs/PRD.md` (v0.1) and `cassini-briefs/CONTRACT.md` (v0.1) on **27 November 2026** using live test execution.

## 1. Implemented Functionality (Verified by Tests)

### Core Engine & REST API (`core/`, `api/`)
- **Contract `v0.1` Endpoints (`api/main.py`):**
  - `GET /health` → `{"status":"ok","contract_version":"0.1"}`
  - `GET /v1/evidence` → `{"items":[Evidence, ...]}` backed by `EIP_EVIDENCE_PATH` (default `sample_data/evidence.json`)
  - `POST /v1/assess` → deterministic assessment with `policy_version: "flood-road-0.1"`
  - Auto-generated OpenAPI schema at `/openapi.json` and Swagger UI at `/docs`
  - CORS restricted to `http://localhost:5173` and `http://127.0.0.1:5173`
- **Strict Input & Evidence Validation (`core/models.py`, `core/store.py`):**
  - Rejects naive timestamps, wrong GeoJSON geometry types, single-point or zero-length `LineString`, out-of-range WGS84 lon/lat coordinates, invalid `claim_type`, and unexpected extra fields with HTTP `422` (no silent repair).
  - Rejects self-intersecting polygons (e.g., bowtie), URL or `..` traversal `raw_path` values, invalid SHA-256 hex strings, and duplicate evidence IDs.
- **Deterministic Spatial/Temporal Assessment Rules (`core/assessment.py`):**
  - Exact Shapely geometry intersections and `coverage.covers(claim)` checks; no invented numerical truth probabilities or `safe`/`true`/`false` statuses.
  - 24-hour historical replay window (accepts observations before or after claim within 24 hours) with `age_hours` (`null` when `observed_at` is unknown).
  - All 8 Contract `v0.1` reason codes implemented and tested: `FLOOD_EXTENT_INTERSECTS`, `NO_MAPPED_OVERLAP`, `OBSERVATION_STALE`, `OBSERVATION_TIME_UNKNOWN`, `COVERAGE_UNKNOWN`, `OUTSIDE_COVERAGE`, `NO_EVIDENCE`, `AUTHENTICATION_FAILED`.
  - Multi-source precedence (`potential_conflict` > `no_mapped_overlap` > `insufficient_evidence`), per-source findings, non-independence caveat, `synthetic` flag propagation, failed-auth exclusion, and explicit unverified-auth limitation.

### Data Connector, Genuine Dataset & Fixtures (`connectors/`, `sample_data/`)
- **CEMS Rapid Mapping Connector (`connectors/cems_rapid_mapping.py`):** Parses downloaded CEMS vector ZIP archives offline, extracts actual `observedEventA` flood extent polygons (not catalogue footprint), documented coverage (`areaOfInterestA` intersected with post-event `imageFootprintA`), acquisition timestamp from `source*.dbf`, and raw ZIP SHA-256 checksum.
- **Genuine Copernicus Dataset:** Imported `EMSR718_AOI02_DEL_MONIT01_v2.zip` (Lough Funshinagh, Co. Roscommon, Ireland) into `sample_data/evidence.json` (`synthetic: false`, 103 unsimplified flood polygons + documented AOI coverage).
- **Synthetic Fixtures & Replay Claims:**
  - 7 deterministic synthetic fixtures generated by `connectors/fixtures.py` under `sample_data/fixtures/` (`fresh_intersection`, `covered_non_intersection`, `stale_observation`, `unknown_observation_time`, `outside_coverage`, `unknown_coverage`, `missing_evidence`).
  - 4 explicitly synthetic replay road claims scoped to Lough Funshinagh in `sample_data/example_claims.json`.

### Evidence Inspector Dashboard (`dashboard/`)
- **Single-Screen Web App (`dashboard/src/App.tsx`, `dashboard/src/components/EvidenceMap.tsx`):**
  - React + TypeScript + Vite + MapLibre GL JS with offline-first WGS84 reference grid style (no commercial map keys; optional online OSM toggle). Verified **0 external network requests** during default offline page load and live assessment.
  - Scenario preset selector + structured WGS84 GeoJSON `LineString` and UTC ISO 8601 timestamp inputs.
  - Renders actual flood extent polygons, documented AOI coverage polygon, and claimed road geometry.
  - Displays `HISTORICAL REPLAY`, `SYNTHETIC INPUT`, and `Live API` vs explicit `Mock Mode` toggle (never silently falls back to mock when the API fails).
  - Sober non-oracle status cards (`Potential conflict`, `No mapped overlap` with explicit *"Not proof of safety or road passability"*, `Insufficient evidence`) — no green "safe" verdict.
  - Displays timestamps, signed temporal offset, reason explanations, provenance/SHA-256, and limitations; surfaces HTTP `422` validation errors and missing evidence states.

### P2 Items (Explicitly Out of Weekend Scope)

### Implementation Caveats (Documented for Transparency)
- **Mock Mode simplification:** Client-side `runMockAssessment` (`dashboard/src/data/presets.ts`) uses bounding-box geometry against a single simplified synthetic polygon; **Live API Mode** evaluates exact Shapely geometry against all 103 genuine EMSR718 polygons.
- **Upstream CEMS topology normalization:** One raw polygon (feature index `2`) in the upstream CEMS `observedEventA_v2.json` archive had a self-touching topological invalidity in Shapely; `connectors/cems_rapid_mapping.py` normalized it via `make_valid()` before unioning while preserving original WGS84 coordinates without simplification. Malformed claim payloads are never repaired and strictly return HTTP `422`.
